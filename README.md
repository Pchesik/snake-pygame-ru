# Пожиратель Змей (Snake Eater) — Русская локализация

Русская версия классической игры «Змейка», написанная на **Python** с использованием библиотеки **PyGame**.

## 🌟 Особенности этой версии
* **Полная локализация:** Все комментарии в коде, заголовок окна, счётчик очков и экран окончания игры переведены на русский язык.
* **Автономность:** Игра состоит всего из **одного файла** и не требует скачивания сторонних картинок или звуков (вся графика рисуется кодом). Никаких ошибок с путями (`FileNotFoundError`).
* **Чистый код:** Сохранены оригинальные алгоритмы, логика и структура отступов автора. Отличный шаблон для обучения и добавления собственных механик.

## 🛠️ Требования
Для запуска игры вам понадобятся установленный **Python 3** и библиотека **PyGame**.

Установка библиотеки через терминал:
```bash
pip install pygame
```

## 🚀 Запуск
Запустите файл игры через терминал или вашу среду разработки (например, VS Code):
```bash
python "Snake Game.py"
```

## 🎮 Управление
* **Движение змейки:** Стрелочки на клавиатуре или клавиши `W`, `A`, `S`, `D`.
* **Выход из игры:** Клавиша `Esc` или закрытие окна.
